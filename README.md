# Python BMI Calculator

A beginner Python project that calculates Body Mass Index (BMI) using a person's height and weight.

## What it does

The program:

1. Takes the user's weight in kilograms
2. Takes the user's height in meters
3. Calculates BMI
4. Displays the BMI category

## Formula

BMI = Weight (kg) / Height² (m²)

## Skills Used

- Python
- Variables
- User input
- Arithmetic operations
- Conditional statements
- Functions
